# Ecualizador-de-5-Bandas-con-ESP32
Un ecualizador de 5 bandas utilizando un microcontrolador ESP32, Potenciómetros deslizables y otras cosas más.

En este momento solo se desarrolla con potenciometros y algunos capacitores, para poder utilizar lo demas hace falta un puerto Jack 3.5mm para conectarlo a um Amplificador de Audio 
Materiales 
+ = Usados
- = No usados
* + ESP32
* + Potenciometro
* + Capacitores
* - Bocina 3W 4 Ohms
